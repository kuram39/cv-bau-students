## Flags / concerns (new)

### F5 — RISKS.md LLM cost section is stale

**Status: documentation drift — misleads cost estimates**

`docs/RISKS.md` still describes **8 LLM calls** per interested candidate
(extract + translate + 3×reason in generic_pass + prefill + translate +
reason in submit). However:

- Deep-research report #7 (merged in #35) explicitly states the
  "precompute ad-side calls" idea was refuted and that "the 8→4 target is
  largely already met."
- `pipeline.py` code confirms `run_generic_pass` defers reasoning (no
  `reason_for_ranking` call in the generic pass, only in
  `submit_role_specific`).
- Actual measured path per interested candidate is approximately:
  `extract (1)` + `translate (1)` in generic_pass;
  `prefill (1)` in express_interest (role-questions are cached per ad);
  `translate (1, lru_cache hit if no new answers)` + `reason (1)` in
  submit_role_specific = **~4–5 net calls**.

**Recommendation:** audit the actual call count with a single debug run
(`grep call_json` trace or `ANTHROPIC_DEBUG=1`), update RISKS.md §LLM
cost to reflect current reality, and close the `perf/llm-cost`
"deferred" item if it's already achieved.
