# IMPROVEMENT_LOG.md

This file is the open notebook for the cv-bau-students pipeline's
self-reflection passes. Each entry is appended by
`scripts/run_reflection.py` (Phase 8.5) and records:

- Observations about *the system*, not the candidates.
- Suggested rubric / prompt adjustments grounded in the batch metadata.
- Open questions that need more data.

The CV text itself, candidate names, and ad URLs are never written
here; the reflection prompt receives only privacy-filtered aggregates.

Reflection entries appear below in reverse-chronological order.
